(and dogfood/validate still clean). Stop condition: streak reaches **3**.

| Field | Value |
|-------|------:|
| streak | **0** |
| last_fire | 2026-07-31 (F45 tool-turns gate H12 + #2 re-score) |
| note | P0 fail-closed shipped + benchmark update → streak stays 0. |
