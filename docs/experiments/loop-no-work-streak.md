# Loop no-work streak

Track consecutive scheduled fires that found **no P0/P1** Luffy product work
(and dogfood/validate still clean). Stop condition: streak reaches **3**.

| Field | Value |
|-------|------:|
| streak | **0** |
| last_fire | 2026-07-31 (F26 default model alignment shipped) |
| note | Reset to 0 whenever a fire ships product work |
